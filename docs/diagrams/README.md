# 픽톡 에이전트 모드 다이어그램

이 디렉토리에는 PickTalk AI 에이전트 모드의 동작 방식과 구조를 보여주는 다이어그램이 포함되어 있습니다.

## 📊 다이어그램

### **picktalk-agent-mode.png** - 픽톡 에이전트 모드 구조
- **파일**: `picktalk-agent-mode.mmd` / `picktalk-agent-mode.png`
- **설명**: PickTalk 챗봇의 AI 에이전트 모드에서 사용자와의 상호작용 및 시스템 동작 방식을 상세하게 보여줍니다
- **포함 내용**:
  - 에이전트 모드 초기화 및 빠른 액션 제공
  - 사용자 입력의 의도 분석 및 분류
  - 주요 기능별 처리 프로세스 (채용공고 작성, 지원자 검색, 이력서 분석, 포트폴리오 생성)
  - AI 에이전트 시스템과의 연동
  - 페이지 네비게이션 및 UI 업데이트
  - 데이터베이스 연동 및 외부 API 호출
  - 에러 처리 및 연속 대화 루프

## 🔧 다이어그램 수정 방법

### Mermaid 문법 사용
다이어그램은 Mermaid 문법으로 작성되어 있습니다. 수정하려면:

1. `.mmd` 파일을 텍스트 에디터로 열어 수정
2. Mermaid CLI를 사용하여 PNG 생성:
   ```bash
   npm install -g @mermaid-js/mermaid-cli
   mmdc -i picktalk-agent-mode.mmd -o picktalk-agent-mode.png
   ```

### 온라인 Mermaid 에디터
- [Mermaid Live Editor](https://mermaid.live/)에서 `.mmd` 파일 내용을 붙여넣어 실시간으로 확인 가능

## 🤖 픽톡 에이전트 모드 특징

### 주요 기능
- **지능형 채용공고 작성**: AI 에이전트가 도와주는 채용공고 생성
- **자동 지원자 검색**: 자연어로 지원자 검색 조건 설정
- **이력서 AI 분석**: 업로드된 이력서의 자동 분석 및 스킬 추출
- **포트폴리오 생성**: GitHub 데이터를 활용한 자동 포트폴리오 생성
- **페이지 네비게이션**: 자연어 명령으로 시스템 내 페이지 이동

### 사용자 경험
- **자연어 인터페이스**: 복잡한 메뉴 없이 자연스러운 대화로 시스템 조작
- **빠른 액션**: 자주 사용하는 기능에 대한 빠른 접근
- **직무 제안**: 채용공고 작성 시 인기 직무 자동 제안
- **연속 대화**: 맥락을 유지하는 자연스러운 대화 흐름

### 기술적 특징
- **LangGraph 에이전트**: 최신 LangGraph 라이브러리를 활용한 지능형 에이전트
- **의도 분류**: 사용자 입력의 의도를 정확하게 파악하여 적절한 툴 실행
- **툴 관리**: 다양한 시스템 기능을 툴로 추상화하여 유연한 확장 가능
- **에러 처리**: 의도 파악 실패 시 명확화 요청을 통한 사용자 경험 개선

## 🔄 에이전트 모드 동작 흐름

1. **에이전트 모드 활성화**: 사용자가 에이전트 모드로 전환
2. **초기화**: 빠른 액션과 직무 제안 제공
3. **사용자 입력**: 자연어로 원하는 작업 요청
4. **의도 분석**: AI가 사용자 의도를 파악하고 적절한 모드 선택
5. **프로세스 실행**: 선택된 모드에 따라 단계별 작업 수행
6. **응답 생성**: 작업 결과를 사용자 친화적으로 응답
7. **연속 대화**: 사용자 피드백에 따라 추가 작업 수행
