- **문제**: `job_posting_id`, `resume_id`, `cover_letter_id` 필드가 ObjectId 타입으로 반환되어 JSON 직렬화 오류 발생
- **해결**: 모든 ObjectId 필드를 문자열로 변환하는 로직 추가
- **영향**: 지원자 관리 API 정상 작동

#### **비동기 함수 호출 문제**
- **문제**: 지원자 상세 조회에서 `get_applicant` 메서드가 비동기 함수가 아님
- **해결**: `get_applicant_by_id` 메서드로 수정하고 `await` 키워드 추가
- **영향**: 지원자 상세 조회 API 정상 작동

#### **API 엔드포인트 경로 문제**
- **문제**: 유사도 검색 엔드포인트 경로가 잘못됨
- **해결**: `/api/similarity/search-similar`로 수정
- **영향**: 유사도 검색 API 정상 작동

#### **요청 모델 구조 문제**
- **문제**: Pick Chatbot 제목 생성 API에서 필수 필드 누락
- **해결**: `form_data`와 `content` 필드 포함하도록 테스트 데이터 수정
- **영향**: 제목 생성 API 정상 작동

#### **임베딩 서비스 폴백 시스템 구현**
- **문제**: OpenAI API 장애 시 서비스 중단 위험
