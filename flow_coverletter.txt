# 📝 자소서 분석 기능 - 초등학생도 이해하는 단계별 설명

## 🎯 자소서 분석이란?
자소서 분석은 지원자가 제출한 자기소개서를 컴퓨터가 읽고, 그 사람이 얼마나 좋은 지원자인지 점수를 매기는 기능입니다.
마치 선생님이 학생의 글쓰기를 채점하는 것과 비슷해요!

## 📚 전체 과정 (총 8단계)

### 1단계: 사용자가 자소서 분석 요청하기
- 사용자가 지원자 관리 페이지에서 지원자를 선택
- "자소서 분석" 버튼을 클릭 (📝 아이콘이 있는 버튼)
- 자소서 분석 모달창이 열림

### 2단계: 자소서 정보 가져오기
- 컴퓨터가 MongoDB 데이터베이스에서 해당 지원자의 자소서를 찾음
- 자소서에는 성장배경, 지원동기, 경력사항, 포트폴리오 등이 들어있음
- 마치 선생님이 학생의 글을 책상에서 가져오는 것과 같아요

### 3단계: AI 분석기 선택하기
- 사용자가 분석 방법을 선택:
  - **OpenAI 분석기**: 인터넷을 통해 GPT-4o-mini AI 사용 (더 정확함)
    - 🤖 **GPT-4o-mini**: 자소서 내용 분석 및 점수 평가
    - 📝 **프롬프트 템플릿**: 구조화된 분석 프롬프트 생성
    - 📊 **JSON 파싱**: AI 응답을 구조화된 데이터로 변환
- 기본값은 OpenAI 분석기입니다

### 4단계: 자소서 내용 정리하기
- AI가 자소서를 읽고 7가지 항목으로 나눔:
  - 🎯 **직무 연관성** (지원한 일과 얼마나 관련있는지)
  - 🧩 **문제 해결** (어려운 문제를 어떻게 해결했는지)
  - 💥 **임팩트** (얼마나 큰 성과를 냈는지)
  - 📖 **명료성** (얼마나 명확하게 썼는지)
  - 💼 **전문성** (전문적인 표현을 사용했는지)
  - ✏️ **문법 및 맞춤법** (글을 얼마나 정확하게 썼는지)
  - 🔑 **키워드 커버리지** (중요한 단어들을 얼마나 포함했는지)
- **사용 기술**: 프롬프트 템플릿으로 구조화된 분석 프롬프트 생성

### 5단계: 각 항목별 점수 매기기
- AI가 각 항목을 0점~10점으로 평가
- **사용 기술**: GPT-4o-mini가 직접 점수 평가
- 점수 기준:
  - 9-10점: 매우 우수 (상위 1%)
  - 8-8.9점: 우수 (상위 10%)
  - 7-7.9점: 양호 (상위 30%)
  - 6-6.9점: 보통 (상위 50%)
  - 5-5.9점: 개선 필요 (하위 50%)
  - 4-4.9점: 부족 (하위 30%)
  - 4점 미만: 매우 부족 (하위 20%)

### 6단계: 전체 점수 계산하기
- 각 항목의 점수를 합쳐서 전체 점수를 만듦 (0-10점 척도)
- **사용 기술**: JSON 파싱으로 구조화된 결과 처리
- 모든 항목을 동일하게 중요하게 평가 (가중치 없음)

### 7단계: 피드백 작성하기
- AI가 지원자의 강점과 개선점을 찾아서 설명을 작성
- **사용 기술**: GPT-4o-mini가 자연어로 피드백 생성
- **STAR 분석**: 상황(Situation), 과제(Task), 행동(Action), 결과(Result) 구조 분석
- **문장 개선**: 원본 문장과 개선된 문장 제안
- **핵심 강점**: 가장 잘한 부분 3가지 추출
- **직무 적합성**: 지원한 직무와 얼마나 맞는지 분석

### 8단계: 결과 보여주기
- 분석이 완료되면 사용자에게 결과를 보여줌
- 화면에 나타나는 것들:
  - 전체 점수와 등급 (0-10점 척도)
  - 각 항목별 점수와 막대 그래프
  - 핵심 강점 목록 (✅ 표시)
  - STAR 사례 분석
  - 문장 개선 제안 (💡 표시)
  - 직무 적합성 분석

## 🔄 추가 기능들

### 재분석하기
- 이미 분석한 자소서를 다시 분석하고 싶을 때 사용
- "재분석" 버튼을 클릭하면 처음부터 다시 분석
- API: POST /api/cover-letters/applicant/{applicant_id}/analysis

### 파일 업로드 분석하기
- 자소서 파일을 직접 업로드하여 분석
- PDF, DOCX, TXT 파일 지원
- API: POST /api/cover-letters/analyze

### 개인정보 마스킹
- 자소서에서 개인정보(이름, 전화번호, 이메일 등)를 자동으로 찾아서 마스킹 처리
- **사용 기술**: GPT-4o-mini로 개인정보 감지 및 마스킹

## 🎨 화면에서 보이는 것들

### 점수 카드
- 각 항목별로 점수가 카드 형태로 표시
- 점수에 따라 색깔이 다름 (높은 점수는 초록색, 낮은 점수는 빨간색)
- 막대 그래프로 시각적 표현

### 등급 표시
- 점수에 따라 등급이 표시됨:
  - 9-10점: 🏆 매우 우수
  - 8-8.9점: ⭐ 우수
  - 7-7.9점: 👍 양호
  - 6-6.9점: ➖ 보통
  - 5-5.9점: ⚠️ 개선 필요
  - 4-4.9점: ❌ 부족
  - 4점 미만: 🚫 매우 부족

### 피드백 섹션
- **핵심 강점**: ✅ 표시와 함께 잘한 부분들 나열
- **STAR 사례**: 📋 표시와 함께 구체적인 경험 사례 분석
- **문장 개선**: 💡 표시와 함께 개선된 문장 제안
- **직무 적합성**: 🎯 표시와 함께 매칭된 스킬과 부족한 스킬 분석

## ⚡ 분석 시간
- 일반적으로 3-5초 정도 소요
- 복잡한 자소서일수록 조금 더 오래 걸림
- 분석 중에는 "분석 중..." 메시지가 표시됨

## 🎯 이 기능의 장점
1. 빠른 분석: 사람이 하루 종일 걸려서 하는 일을 몇 초 만에 완료
2. 공정한 평가: 모든 지원자를 같은 기준으로 평가
3. 구체적인 피드백: 단순한 점수가 아닌 구체적인 조언 제공
4. STAR 분석: 체계적인 경험 사례 분석
5. 문장 개선: 실제로 사용할 수 있는 개선 제안

## 🔧 기술적 설명 (고급)

### 🤖 **AI 기술 스택**
- **OpenAI**: GPT-4o-mini (자소서 분석)
- **프롬프트 엔지니어링**: 
  - 요약 & 핵심강점 추출 프롬프트
  - STAR 추출 프롬프트
  - 직무 적합성 점수 프롬프트
  - 문장별 개선 프롬프트
  - 평가 루브릭 점수화 프롬프트
  - 종합 분석 프롬프트
  - 개인정보 마스킹 프롬프트
- **JSON 파싱**: 구조화된 분석 결과 처리

### 🏗️ **시스템 아키텍처**
- 백엔드: Python FastAPI로 서버 구축
- 프론트엔드: React로 사용자 인터페이스 구성
- 데이터베이스: MongoDB에 자소서 정보 저장
- API 엔드포인트: 
  - POST /api/cover-letters/analyze (파일 업로드 분석)
  - POST /api/cover-letters/applicant/{applicant_id}/analysis (지원자 자소서 분석)
  - GET /api/cover-letters/{cover_letter_id} (자소서 조회)
  - DELETE /api/cover-letters/{cover_letter_id} (자소서 삭제)

### 📊 **분석 모델 구조**
- **CoverLetterAnalysis**: 전체 분석 결과
- **EvaluationRubric**: 7개 항목별 점수 (0-10점)
- **STARAnalysis**: STAR 구조 분석 결과
- **TopStrength**: 핵심 강점 3가지
- **JobSuitability**: 직무 적합성 분석
- **SentenceImprovement**: 문장 개선 제안

## 📋 실제 사용 방법
1. 지원자 관리 페이지에서 지원자 선택
2. "자소서 분석" 버튼 클릭 (📝 아이콘)
3. 분석 타입 선택 (기본값: comprehensive)
4. "분석 시작" 버튼 클릭
5. 3-5초 후 결과 확인

이렇게 자소서 분석 기능은 사용자가 버튼 하나만 클릭하면 AI가 자동으로 자소서를 읽고, 7개 항목으로 점수를 매기고, STAR 분석과 문장 개선 제안까지 제공하는 똑똑한 시스템입니다! 🚀
